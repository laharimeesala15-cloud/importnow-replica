# ImportNow Website Replica

A responsive replica of the ImportNow website, built as part of a practical assignment.

## Project Overview

This project recreates the ImportNow website, showcasing China-to-India import services, sourcing, shipping, business trips, and related services.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- AI assistance (ChatGPT, Claude)

## Features

- Responsive website layout
- Interactive 3D globe
- Animated shipment journey
- Services and industries sections
- FAQ section
- Contact section
- WhatsApp contact button

## Purpose

Created as a practical assignment to demonstrate website development, UI recreation, interactive elements, and AI-assisted development.
